# Laboratory 02 - Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focused on cloud infrastructure. I investigated a Linux server using KillerCoda and learned about compute, storage, networking, and operating system resources. I also compared AWS, Microsoft Azure, and Google Cloud Platform.

## Objectives

- Understand the main parts of cloud infrastructure.
- Investigate a Linux cloud server.
- Identify compute, storage, networking, and operating system resources.
- Compare AWS, Azure, and Google Cloud services.
- Create a simple cloud infrastructure diagram.
- Improve my technical documentation skills.

## Cloud Infrastructure Components

The main cloud infrastructure components are:

- Compute
- Storage
- Networking
- Operating System
- Identity and Access Management

These components work together to provide cloud services and allow applications to run properly.
