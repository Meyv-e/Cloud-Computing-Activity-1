# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

For me, compute is one of the most important cloud infrastructure components. Compute provides the CPU and memory needed to run applications and services. Without compute resources, applications cannot process tasks or respond to users.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing an operating system for cloud servers. It has many useful command-line tools that allow users to check and manage server resources. In this laboratory, I used Linux commands to check the CPU, RAM, storage, hostname, and network information.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it helps engineers understand the system before deploying it. It also provides a record of the resources, settings, and decisions used in the infrastructure. Good documentation can make troubleshooting and future changes easier.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux server using terminal commands. I also learned how to identify compute, storage, networking, and operating system resources. I learned more about the differences between AWS, Microsoft Azure, and Google Cloud Platform. I also practiced creating Markdown files and organizing files in GitHub.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio became more organized because I added a new laboratory folder with different Markdown files and screenshots. I also learned how to document my work properly. This activity helped me make my portfolio more complete and showed my progress in learning cloud computing.

## Conclusion

Overall, this laboratory helped me understand the basic parts of cloud infrastructure. I learned that compute, storage, networking, and operating systems work together to support cloud applications. I also learned that proper documentation is important for planning and managing cloud infrastructure.
