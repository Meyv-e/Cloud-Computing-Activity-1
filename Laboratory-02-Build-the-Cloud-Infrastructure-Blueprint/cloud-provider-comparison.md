# Cloud Provider Comparison

## Comparison Table

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Google Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Google Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID | Google Cloud IAM |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers a very broad range of cloud services. It provides many services for computing, storage, networking, security, databases, and other cloud needs. :contentReference[oaicite:3]{index=3}

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure. It works well with Microsoft products and services, and Microsoft Entra ID provides identity and access management for Microsoft cloud services. :contentReference[oaicite:4]{index=4}

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud Platform is a strong choice for AI, ML, and Kubernetes. Google Cloud provides AI and Machine Learning services and also offers Google Kubernetes Engine (GKE). :contentReference[oaicite:5]{index=5}

### 4. What similarities did you observe among the three cloud providers?

All three cloud providers offer compute, storage, networking, and identity services. They use different service names, but their main purpose is similar: to provide cloud resources that organizations can use to build and run applications.
