# Cloud Infrastructure Components

## 1. Compute Resources

### Purpose

Compute resources provide the processing power needed to run programs and applications.

### Importance in Cloud Computing

Compute resources are important because cloud applications need CPU and memory to work. They can also be increased when more computing power is needed.

### Relation to KillerCoda

The KillerCoda Linux server uses CPU and RAM to run commands, programs, and services. The CPU and CPU cores are examples of compute resources.

---

## 2. Storage Resources

### Purpose

Storage resources are used to save files, programs, and data.

### Importance in Cloud Computing

Storage is important because applications need a place to save and retrieve data. Cloud storage also helps keep data available.

### Relation to KillerCoda

The Linux server has disk storage and mounted file systems. These are used to store the operating system, files, and other data.

---

## 3. Networking Resources

### Purpose

Networking resources allow computers and cloud services to communicate with each other.

### Importance in Cloud Computing

Networking is important because users need to connect to cloud applications and services. It also allows different cloud resources to communicate.

### Relation to KillerCoda

The KillerCoda server has a network connection and an IP address. The IP address helps identify the server on the network.

---

## 4. Operating System

### Purpose

The operating system manages the computer's hardware and software.

### Importance in Cloud Computing

An operating system allows applications and services to run on a cloud server. Linux is commonly used for cloud servers because it provides useful tools for managing servers.

### Relation to KillerCoda

KillerCoda provides a Linux environment where we can use terminal commands to inspect and manage the server.
