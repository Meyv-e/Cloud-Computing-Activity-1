# Cloud Platform Recommendations

## Client A – Startup Company

### Recommended Platform: Amazon Web Services (AWS)

AWS is recommended because it offers many services that can help a startup create and launch a mobile application without having to manage physical servers. The company can start with smaller resources and increase them as the number of users grows. AWS also has managed services that can make infrastructure management easier for a small development team.

### Recommended Services

* **Amazon EC2** – Provides virtual computing resources for running applications.
* **Amazon S3** – Provides scalable storage for files, images, backups, and application data.
* **Amazon RDS** – Provides a managed relational database for storing application data.
* **Amazon CloudFront** – Helps deliver application content to users through a global content delivery network.

---

## Client B – University

### Recommended Platform: Microsoft Azure

Azure is recommended because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure works well with these Microsoft technologies, which can make migration and identity management easier. The university can also connect its existing infrastructure to Azure and slowly move selected workloads to the cloud instead of moving everything at once.

### Recommended Services

* **Azure Virtual Machines** – Can be used to run Windows Server workloads in the cloud.
* **Microsoft Entra ID** – Provides identity and access management for users and resources.
* **Azure SQL Database** – Provides a managed SQL database service.
* **Azure Virtual Network** – Provides networking for Azure resources and connections to the university's existing infrastructure.

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform (GCP)

Google Cloud is recommended because the company focuses on Artificial Intelligence and Machine Learning, which can require powerful computing resources. Google Cloud offers services and infrastructure that support AI and machine learning development. Its data analytics and Kubernetes services can also be useful for research projects and applications that need to scale.

### Recommended Services

* **Compute Engine** – Provides virtual machines for high-performance computing workloads.
* **Google Kubernetes Engine (GKE)** – Provides managed Kubernetes for applications running in containers.
* **Vertex AI** – Provides tools for developing and deploying machine learning models.
* **Cloud Storage** – Provides scalable storage for datasets, models, and research files.

---

## Client D – Global E-Commerce Company

### Recommended Platform: Amazon Web Services (AWS)

AWS is recommended because the company operates in different parts of the world and needs infrastructure that is reliable and can handle a large number of users. AWS has multiple Regions and Availability Zones that can help keep applications available and reliable. It also provides services that can automatically adjust computing resources and distribute traffic across different servers. These features make AWS a good choice for a large international e-commerce company.

### Recommended Services

* **Amazon EC2** – Provides scalable computing resources for websites and application servers.
* **Elastic Load Balancing** – Distributes incoming traffic across multiple resources.
* **Amazon EC2 Auto Scaling** – Automatically increases or decreases computing resources depending on workload requirements.
* **Amazon RDS** – Provides managed relational databases for storing e-commerce data.
* **Amazon CloudFront** – Helps deliver website content to users through a global content delivery network.
