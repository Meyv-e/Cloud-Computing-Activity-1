# Amazon Web Services (AWS) Research

## 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform owned by Amazon. It provides different cloud services that businesses and organizations can use to create, run, and manage applications without needing to maintain their own physical servers and equipment. AWS offers services for computing, storage, databases, networking, security, analytics, artificial intelligence, and many other purposes.

## 2. Global Infrastructure

AWS has a large cloud infrastructure around the world that is divided into **Regions** and **Availability Zones**. A Region is a specific geographic location, while Availability Zones are separate locations within a Region. This setup helps organizations place their applications closer to their users and also helps keep their systems available even if one location has a problem. AWS also has **Local Zones** and **Wavelength Zones** for applications that need resources closer to their users or certain networks.

## 3. Cloud Management Console

The **AWS Management Console** is a website where users can access and manage different AWS services. It gives users one place to search for services, manage their cloud resources, check notifications, use CloudShell, and manage their AWS account.

## 4. Four Core Services

### Amazon EC2

**Amazon Elastic Compute Cloud (Amazon EC2)** provides virtual servers that users can use to run applications and other workloads in the AWS cloud.

### Amazon S3

**Amazon Simple Storage Service (Amazon S3)** is a storage service used for saving and accessing files, backups, data, and other types of digital objects.

### Amazon RDS

**Amazon Relational Database Service (Amazon RDS)** is a service that helps users set up, manage, and scale relational databases in the cloud without having to handle all the database hardware themselves.

### Amazon VPC

**Amazon Virtual Private Cloud (Amazon VPC)** allows users to create a private and separate network in AWS where they can securely place and manage their cloud resources.

## 5. Three Advantages

1. **Many available services** – AWS has a lot of services for computing, storage, databases, networking, security, analytics, and other technologies.
2. **Global infrastructure** – AWS has Regions and Availability Zones in many parts of the world, allowing organizations to choose a location that works best for their applications and users.
3. **Scalable and flexible** – AWS allows users to increase or decrease their cloud resources depending on how much they need at a certain time.

## 6. Typical Enterprise Use Cases

Many companies use AWS for websites and mobile applications, storing and backing up data, hosting databases, developing software, disaster recovery, data analysis, and other large business applications. Companies can also use several AWS services together to create systems that are reliable, available, and able to handle different amounts of workload.
