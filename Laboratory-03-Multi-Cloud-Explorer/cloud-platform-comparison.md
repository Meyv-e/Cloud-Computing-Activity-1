## 1. Which cloud provider offers the broadest range of services?

AWS offers a very wide range of cloud services compared to the other major cloud providers. It has services for computing, storage, databases, networking, security, analytics, artificial intelligence, and many other areas.

## 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure has the best integration with Microsoft technologies. It works well with products such as Windows Server, Microsoft 365, Microsoft Entra ID, SQL Server, and other Microsoft services.

## 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is known for being strong in **Artificial Intelligence, Machine Learning, and Kubernetes**. It provides different AI and machine learning services, as well as **Google Kubernetes Engine (GKE)**, which helps manage applications running in containers.

## 4. Which cloud platform would you personally choose and why?

I would personally choose **Amazon Web Services (AWS)** because it offers many different services and gives users more choices when creating and scaling applications. Its large global infrastructure and wide selection of services make it useful for different kinds of projects, whether they are small applications or large business systems.
