# Microsoft Azure Research

## 1. Brief Overview

Microsoft Azure is a cloud computing platform created by Microsoft. It provides different cloud services that organizations can use to build, run, manage, and improve their applications and IT systems. Azure has services for computing, storage, networking, databases, security, analytics, artificial intelligence, and software development.

## 2. Global Infrastructure

Azure has a large cloud infrastructure with regions and data centers located in different parts of the world. These regions allow organizations to choose where they want to run their applications and services. Azure also has **Availability Zones** in supported regions, which help keep applications running and make them more reliable if there is a problem with one location.

## 3. Cloud Management Console

The **Azure Portal** is Microsoft's website for managing Azure services. Users can use it to create, set up, monitor, and manage their Azure resources. It also gives access to features such as services, resource groups, dashboards, subscriptions, and other cloud management tools.

## 4. Four Core Services

### Azure Virtual Machines

**Azure Virtual Machines** provide virtual computers that organizations can use to run different operating systems, applications, and workloads in the cloud.

### Azure Blob Storage

**Azure Blob Storage** is a storage service used to store large amounts of unstructured data. This can include documents, images, videos, backups, and application files.

### Azure Virtual Network

**Azure Virtual Network** allows users to create private networks within Azure. It helps connect cloud resources securely and can also connect Azure resources to an organization's own network.

### Azure SQL Database

**Azure SQL Database** is a managed database service based on Microsoft SQL Server. It allows organizations to use SQL databases in the cloud without having to manage the physical database infrastructure themselves.

## 5. Three Advantages

1. **Good Microsoft integration** – Azure works well with other Microsoft products and technologies such as Windows Server, Microsoft 365, Active Directory, and SQL Server.
2. **Global infrastructure** – Azure has regions and data centers in many different parts of the world, giving organizations more choices for where to run their applications.
3. **Many enterprise features** – Azure provides services for security, identity, networking, databases, analytics, artificial intelligence, and hybrid cloud environments.

## 6. Typical Enterprise Use Cases

Many companies use Azure to host applications, run Windows Server workloads, manage databases and virtual machines, support Microsoft-based business systems, perform data analytics, use artificial intelligence, and handle backups and disaster recovery. Azure is also useful for organizations that already use Microsoft products because their existing systems can be connected with Azure services.
