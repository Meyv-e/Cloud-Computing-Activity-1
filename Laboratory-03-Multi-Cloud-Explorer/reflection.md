# Checkpoint 8 – Mission Reflection

## Mission Reflection

During this mission, the cloud platform that impressed me the most was **Amazon Web Services (AWS)**. I learned that AWS provides many services for computing, storage, networking, databases, security, and application development. It can support both small startups and large companies because its resources can be increased or decreased depending on the number of users and workload.

I also studied **Microsoft Azure** and **Google Cloud Platform (GCP)**. I learned that all three platforms provide similar cloud services, but each has different strengths. AWS has a wide range of services, Azure works well with Microsoft technologies, and GCP is strong in artificial intelligence, machine learning, data analytics, and Kubernetes.

One important thing I learned is that choosing a cloud provider depends on the **organization's needs**. Factors such as budget, existing technology, security, performance, scalability, and future plans should be considered. For example, Azure is suitable for organizations already using Microsoft products, while GCP can be a good choice for AI-related projects. AWS is useful for organizations that need many different cloud services.

The **client recommendations** helped me understand how cloud platforms can be matched to different business situations. The **Linux server investigation** also taught me how commands such as `lscpu`, `free -h`, and `df -h` can provide important server information for cloud migration.

Overall, this mission improved my understanding of **cloud computing**. I learned more about AWS, Azure, GCP, Linux servers, and cloud decision-making. I also learned that selecting the right cloud platform requires understanding the client's requirements and choosing services that fit their goals and resources.
