# Reflection

## 1. Why is Object Storage a good choice for the client's photo-sharing application?

Object Storage is a good choice because it is designed for storing large amounts of unstructured data such as images. It can store many photos and allows applications to access the files easily.

## 2. What did you learn about using Docker for cloud infrastructure?

I learned that Docker can be used to deploy services in a controlled environment. It can run applications using containers and allows different services to be deployed using Docker commands.

## 3. What is a bucket, and why is it important?

A bucket is a container used to organize and store objects in Object Storage. In this activity, the required bucket name was client-photos. It would be used to store the client's uploaded photos.

## 4. How does Object Storage help enterprises manage large amounts of data?

Object Storage helps enterprises manage large amounts of data because it is designed for unstructured data such as images, videos, and backups. It also organizes data as objects with metadata and unique identifiers.

## 5. How confident are you in using Linux commands after this activity?

After this activity, I am more familiar with using Linux commands and Docker commands in the terminal. I also learned how cloud storage services can be deployed using containers. Although I was not able to successfully deploy MinIO because of the Docker image pull error, the activity helped me understand the process better.
